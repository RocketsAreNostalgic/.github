## Admin Shell coverage drift pilot — 29 September 2026

[Admin Shell #19](https://github.com/RocketsAreNostalgic/ran-admin-shell/pull/19) is the first bounded #65 semantic coverage-drift proof after the original #13 acceptance. `composer check:coverage` checks discovered maintained PHP and the configured Composer CLI against direct PHPStan and PHPCS paths; it fails closed on new extensionless CLI entries and imported/excluded PHPStan configuration that requires review. PHPCS exclusions are interpreted with the locked PHPCS 3.13.6 absolute/relative regex behavior. The PHPStan `resources/` root now includes future resource PHP; tools remain a directory root and the CLI an explicit file root. Test and fixture PHP retain their independent checks. Negative controls introduce root and nested uncovered PHP, narrow a resource path, add global PHPCS exclusions, import PHPStan configuration and add a second Composer CLI. The guard is excluded from the installed package export.

Exact-head [Quality 36536753570](https://github.com/RocketsAreNostalgic/ran-admin-shell/actions/runs/36536753570) passed both PHP 8.0/8.5 lanes, 26 tests and 173 assertions; five review threads were answered and resolved, and GitGuardian passed. Squash merge `e7f3a479de0678e5f96cf37d13295cd3c1f6d5a7` retains the PR tree `666fb5c8ae79d6db68efcfac0c692694b2773da8`. The repository workflow is PR-only; tree identity carries the exact-head qualification without inventing a post-merge run. This is one repository pilot; the broader #65 drift criterion stays open for the rest of the estate.

## TnySignature PHPStan source drift — 29 September 2026

The existing PHPStan level-5 selection was a list of individual root entry points plus `lib/`; the earlier quality test compared that list with a fixed expected list. A future root PHP file could be shipped by the installed WordPress workflow while both lists stayed unchanged. [TnySignature #9](https://github.com/RocketsAreNostalgic/tnySignature/pull/9) now enumerates first-party PHP (excluding test and dependency trees) and requires each path to fall under a directly selected PHPStan path. Its isolated fixture demonstrates rejection of a new root file. The check is part of existing terminal quality; PHPStan configuration and published plugin files are unchanged. Exact-head [Quality 36557273671](https://github.com/RocketsAreNostalgic/tnySignature/actions/runs/36557273671) passed baseline, WordPress 5.3 and 7.1.2 integration, and terminal quality; the independent exact-head review found no major issues. Squash merge `d438225c4ec5513a57e464b41e5f203a5498a65a` retains the qualified tree `e77a99dd02faa92f471fa6e10ac88e6eee4a3357`. The estate-wide #65 drift criterion remains open.
