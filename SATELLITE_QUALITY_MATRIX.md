PHPStan floors differ because they were raised to the highest evidenced, blocking level accepted within each repository's current support floor, without blanket baselines. Source and tools use their repository-specific coverage; an analysis-only WordPress bootstrap is excluded from PHPUnit discovery where applicable. Formatting and source-syntax controls preserve supported PHP and archive identities. Review and native checks qualify each merged slice; WordPress UI and owner-verified end-to-end behaviour remain separately held.

Release migrations for the five distribution plugins were previously completed. Their quality-only `ci:`, `test:` and `docs:` commits did not request release publication or replace immutable artifacts. Admin Shell is a build-time Composer library. No publication is claimed from this matrix.
