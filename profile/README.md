# Rockets Are Nostalgic [RAN]

WordPress plugins and tools for developers.

## RAN Booster is coming

RAN Booster is your launch pad for deploying your WordPress plugins and themes directly from Git repositories you control.

It comes with support for public and private GitHub repos built in, and more Git providers on the way. With Booster, your WordPress site talks directly to GitHub, so there is no RAN-operated licensing service, OAuth relay or deployment proxy phoning home along the way.

Booster enables a plugin or theme to track a branch and, with webhooks, allows Push-to-Deploy. However, my favorite approach is a full PR → CI → Release workflow, so Booster can follow published GitHub releases and let WordPress offer—or, when set to Automatic, install—an eligible update through its own update system.

The public beta will focus on single-site WordPress and GitHub. I am finishing the release work, documentation and installable package now. The repository will become public when the beta opens.
