# Rockets Are Nostalgic organisation guidance

For ordinary development or review, read [Contributing](CONTRIBUTING.md) and
[Quality Standards](docs/quality/QUALITY_STANDARDS.md), then the repository's local
`AGENTS.md`, development instructions and required checks. Local requirements
remain authoritative; the organisation baseline does not lower stronger gates.

## Specialist reading when needed

| Task | Reference |
| --- | --- |
| Change CI or branch protection | [Workflow contract](docs/quality/QUALITY_WORKFLOWS.md), [rulesets](docs/quality/REPOSITORY_RULESETS.md); [enforcement design](quality-enforcement/README.md) when changing that boundary. |
| Prepare or operate a release | Local release guide and [release trust](docs/release/RELEASE_TRUST.md), then the applicable [Profile A](docs/release/RELEASE_PROFILE_A.md) or [Profile B](docs/release/RELEASE_PROFILE_B.md). |
| Implement bootstrap templates | [Frozen contract and examples](docs/release/BOOTSTRAP_STARTER_CONTRACT.md). |
| Change contribution or support intake | [Community inheritance and overrides](docs/COMMUNITY_STANDARDS.md); [support](SUPPORT.md), [security](SECURITY.md) and [conduct](CODE_OF_CONDUCT.md) define reporting boundaries. |

## Work and acceptance

Current ownership and evidence live in existing issues: [quality #65](https://github.com/RocketsAreNostalgic/.github/issues/65)
and [sibling verification #136](https://github.com/RocketsAreNostalgic/.github/issues/136);
[release acceptance #57](https://github.com/RocketsAreNostalgic/.github/issues/57),
[administrative readback #59](https://github.com/RocketsAreNostalgic/.github/issues/59),
[delivery #81](https://github.com/RocketsAreNostalgic/.github/issues/81) and
[onboarding #85](https://github.com/RocketsAreNostalgic/.github/issues/85).
Onboarding acceptance remains mandatory before feature completion. UI/manual
acceptance and Plugin Library deferrals remain until an explicit newer owner
decision supersedes them; automated success cannot clear a manual hold.

[Earlier guidance and evidence](https://github.com/RocketsAreNostalgic/.github/tree/70df865a00734542e6bb663e684d86b8b4757b8e)
remain available through Git history for optional provenance and old-link recovery.
