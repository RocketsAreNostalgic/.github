# Rockets Are Nostalgic organization defaults

This repository contains the default community-health files inherited by repositories in the Rockets Are Nostalgic organization when a repository does not provide a local equivalent.

The governing policy is [COMMUNITY_STANDARDS.md](COMMUNITY_STANDARDS.md). Repository-local files may extend or replace these defaults when project-specific guidance is required, but they must preserve the organization-wide safety and disclosure boundaries defined there.

Engineering policy is documented in [ENGINEERING.md](ENGINEERING.md), [QUALITY_STANDARDS.md](QUALITY_STANDARDS.md), [QUALITY_WORKFLOWS.md](QUALITY_WORKFLOWS.md), [REPOSITORY_RULESETS.md](REPOSITORY_RULESETS.md), and [RELEASE_TRUST.md](RELEASE_TRUST.md).
